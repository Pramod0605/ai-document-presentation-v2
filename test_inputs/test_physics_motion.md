# Physics: Motion and Newton's Laws

## Topic 1: Describing Motion

Motion is described using several key quantities that relate position, velocity, and acceleration over time.

### Displacement and Distance
- **Distance**: Total path length traveled (scalar)
- **Displacement**: Change in position from start to end (vector)

$$\vec{d} = \vec{r}_{final} - \vec{r}_{initial}$$

### Velocity and Speed
- **Speed**: Rate of distance traveled (scalar)
- **Velocity**: Rate of displacement change (vector)

Average velocity:
$$\bar{v} = \frac{\Delta x}{\Delta t} = \frac{x_2 - x_1}{t_2 - t_1}$$

Instantaneous velocity:
$$v = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t} = \frac{dx}{dt}$$

### Acceleration
Rate of change of velocity:
$$a = \frac{\Delta v}{\Delta t} = \frac{v_2 - v_1}{t_2 - t_1}$$

Or instantaneously:
$$a = \frac{dv}{dt} = \frac{d^2x}{dt^2}$$

## Topic 2: Kinematic Equations

For motion with constant acceleration, these equations relate position, velocity, acceleration, and time:

### The Four Kinematic Equations

1. $$v = v_0 + at$$

2. $$x = x_0 + v_0 t + \frac{1}{2}at^2$$

3. $$v^2 = v_0^2 + 2a(x - x_0)$$

4. $$x = x_0 + \frac{1}{2}(v_0 + v)t$$

Where:
- $x_0$ = initial position
- $v_0$ = initial velocity
- $a$ = constant acceleration
- $t$ = time elapsed
- $x$ = final position
- $v$ = final velocity

### Free Fall
Objects in free fall near Earth's surface experience:
$$a = g = 9.8 \text{ m/s}^2$$ (downward)

## Topic 3: Newton's Laws of Motion

### First Law (Law of Inertia)
An object at rest stays at rest, and an object in motion stays in motion with constant velocity, unless acted upon by a net external force.

$$\sum \vec{F} = 0 \Rightarrow \vec{v} = \text{constant}$$

### Second Law (F = ma)
The acceleration of an object is directly proportional to the net force and inversely proportional to its mass.

$$\vec{F}_{net} = m\vec{a}$$

Or in component form:
$$\sum F_x = ma_x, \quad \sum F_y = ma_y$$

### Third Law (Action-Reaction)
For every action force, there is an equal and opposite reaction force.

$$\vec{F}_{A \text{ on } B} = -\vec{F}_{B \text{ on } A}$$

## Worked Example

A car accelerates from rest at 3.0 m/s² for 5.0 seconds. How far does it travel?

**Given:** $v_0 = 0$, $a = 3.0$ m/s², $t = 5.0$ s

**Solution:**
Using $x = v_0 t + \frac{1}{2}at^2$:
$$x = 0 + \frac{1}{2}(3.0)(5.0)^2 = 37.5 \text{ m}$$
