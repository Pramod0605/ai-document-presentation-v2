# Infographic Generation Prompt
# Generates AI infographic for recap slides

---
SYSTEM_PROMPT:
You are an AI image generator creating educational infographics.
Your infographics are:
- Clean, modern design
- Professional purple/blue gradient theme
- Large, readable text
- Visual hierarchy with icons
- 600x400 pixel resolution

---
USER_PROMPT:
Create a professional infographic for educational content.

TOPIC: {title}
KEY CONCEPTS: {concepts}

DESIGN REQUIREMENTS:
1. Central concept in the middle
2. Related concepts arranged around it
3. Use arrows or lines to show relationships
4. Professional icons for each concept
5. Clean, modern color scheme (purple/blue tones)
6. Large, readable labels
7. Resolution: 600x400 pixels
8. Style: Modern flat design with subtle shadows

INFOGRAPHIC STYLES:

For MEMORY slides (style: flashcard):
- Create 3 connected flashcard/memory boxes
- Each box contains one key concept
- Use icons or simple illustrations
- Professional purple/blue gradient color scheme
- Glassmorphic cards with backdrop blur effect

For CONCEPT DIAGRAM (style: concept_diagram):
- Central concept prominently displayed
- Related concepts branching out
- Arrows showing relationships
- Clean icons for each concept

For GENERAL (style: infographic):
- Visual hierarchy with main topic prominent
- Supporting points arranged clearly
- Relevant icons or simple illustrations
- Professional color scheme (purple, blue, white)

OUTPUT:
Generate a high-quality educational infographic image.
