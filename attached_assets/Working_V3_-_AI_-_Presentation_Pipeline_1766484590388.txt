Overview
The V3 pipeline transforms a PDF document into an interactive video presentation with synchronized narration, animated slides, and an AI avatar overlay.

B. Python Pipeline (run_v3_combined.py)
def run_v3_pipeline(input_file: str):
    # Step 1: Parse Datalab JSON
    json_data = parse_datalab_json(input_file)
    
    # Step 2: Clean content for LLM
    topic, blocks, images = clean_content_for_llm(json_data)
    
    # Step 3: LLM generates slides + narration (single call)
    slides = call_combined_chunker_narrator(blocks)
    
    # Step 4: Generate audio with Edge TTS
    for slide in slides:
        audio_path = generate_audio(slide['narration'])
        slide['audio_path'] = audio_path
    
    # Step 5: Generate recap images (if recap slide)
    for slide in slides:
        if slide['slide_type'] == 'recap':
            images = generate_recap_images(slide['storyboard'])
    
    # Step 6: Render HTML slides
    for slide in slides:
        html = render_template(slide)
        save_html(slide['index'], html)
    
    # Step 7: Generate presentation player
    generate_presentation_player(slides)

Key Features
Slide Navigation

Loads slides via iframe: html/slide_001.html, slide_002.html, etc.
Slide markers on timeline for quick seeking
Audio Sync

Each slide has its own audio file
Player coordinates audio playback with slide content
timeupdate events trigger segment reveals
Segment-Level Sync

// Inside each slide's script
audio.addEventListener('timeupdate', () => {
  const currentTime = audio.currentTime;
  segments.forEach((seg, i) => {
    if (currentTime >= seg.startTime) {
      showSegment(i);
    }
  });
});
Auto-Advance

// Slide notifies parent when audio ends
audio.addEventListener('ended', () => {
  parent.postMessage({ type: 'slideComplete' }, '*');
});
// Player receives message and advances
window.addEventListener('message', (e) => {
  if (e.data.type === 'slideComplete' && isPlaying) {
    loadNextSlide();
  }
});
